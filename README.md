## 🎓 Project Overview

This is a **Projet de Fin d'Études (PFE)** - Final Year Project focusing on the automation of a semoline transport line. The project was developed using **Siemens TIA Portal V16** and demonstrates industrial automation principles applied to food processing industry.

## 🏭 Project Description

**Line Automatique de Transport de Semoline** (Automated Semoline Transport Line) is a complete industrial automation system designed to control and monitor the transport of semolina in a food processing facility. The system ensures efficient, safe, and automated material handling with real-time monitoring and control capabilities.

## ✨ Key Features

- 🏭 Complete TIA Portal V16 automation project
- 🔄 Automated transport line control
- 📊 Real-time monitoring and supervision
- ⚡ Safety interlocks and emergency systems
- 🎛️ HMI interface for operator control
- 🔧 Industrial communication protocols
- 📈 Production tracking and data logging
